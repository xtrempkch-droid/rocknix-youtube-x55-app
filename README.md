# YouTube App for X55 & R36S (Rocknix/ArkOS/JELOS)

Uma interface leve e navegável via controle (D-Pad) para assistir YouTube em dispositivos portáteis Linux.

## ✨ Características
- **Interface TUI:** Otimizada para telas de 3.5" (R36S) e 5.5" (X55).
- **Aceleração de Hardware:** Utiliza MPV com suporte ao chip RK3566.
- **Auto-Update:** Verifica e atualiza o `yt-dlp` automaticamente.
- **Resolução Inteligente:** 720p para X55 e 480p para R36S.

## 🚀 Instalação Rápida
Conecte-se via SSH ao seu dispositivo e cole o comando abaixo:

curl -sL https://raw.githubusercontent.com/xtrempkch-droid/rocknix-youtube-x55-app/main/install.sh | bash

## 🎮 Controles
- **D-Pad:** Navegar na lista de vídeos.
- **Botão A / Enter:** Selecionar e Reproduzir.
- **Botão X / S:** Focar na barra de busca.
- **Botão B / Esc:** Voltar/Sair.
