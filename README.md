📺 YouTube App for X55 & R36S (Rocknix/ArkOS/JELOS)

Português | English
<a name="português"></a>🇧🇷 Português

Uma interface leve (TUI) e navegável via botões físicos para assistir YouTube em dispositivos portáteis Linux (Powkiddy X55, R36S, etc).
✨ Características

    Interface Otimizada: Design focado em telas de 3.5" (4:3) e 5.5" (16:9).

    Aceleração de Hardware: Utiliza MPV com suporte aos chips Rockchip (RK3566/RK3326).

    Instalação Automática: Instala dependências e se auto-atualiza para evitar erros do YouTube.

    Resolução Inteligente: Auto-ajuste para 720p (X55) ou 480p (R36S).

🚀 Instalação Rápida

Conecte-se ao seu console via SSH e cole o comando abaixo:
Bash

curl -L https://raw.githubusercontent.com/xtrempkch-droid/rocknix-youtube-x55-app/main/install.sh | bash

Após instalar, reinicie o EmulationStation para ver o ícone na seção Ports.
🎮 Controles

    D-Pad (Setas): Navegar na lista de vídeos.

    Botão A / Enter: Selecionar e Reproduzir.

    Botão X / S: Focar na barra de busca.

    Botão B / Esc: Sair do vídeo ou do App.

🛠️ Solução de Problemas (FAQ)

    O app fecha ao abrir: Verifique se o Wi-Fi está ligado. O app precisa de internet no primeiro boot para baixar bibliotecas.

    Vídeo lento: O sistema limita a 720p. Se travar, verifique a estabilidade do seu sinal Wi-Fi.

    Busca não funciona: Certifique-se de que o yt-dlp está atualizado executando o instalador novamente.

<a name="english"></a>🇺🇸 English

A lightweight TUI (Terminal User Interface) designed for handheld Linux consoles (Powkiddy X55, R36S, etc), fully navigable via physical buttons.
✨ Features

    Optimized UI: Designed for 3.5" (4:3) and 5.5" (16:9) screens.

    Hardware Acceleration: Uses MPV with Rockchip GPU support (RK3566/RK3326).

    Auto-Installation: Automatically installs dependencies and updates itself.

    Smart Resolution: Defaults to 720p (X55) or 480p (R36S) for best performance.

🚀 Quick Installation

Connect to your handheld via SSH and paste the following command:
Bash

curl -L https://raw.githubusercontent.com/xtrempkch-droid/rocknix-youtube-x55-app/main/install.sh | bash

After installation, restart EmulationStation to find the app in the Ports section.
🎮 Controls

    D-Pad (Arrows): Navigate the video list.

    A Button / Enter: Select and Play.

    X Button / S: Focus on the search bar.

    B Button / Esc: Exit video or App.

🛠️ Troubleshooting (FAQ)

    App closes immediately: Ensure Wi-Fi is on. The app needs internet on the first boot to download dependencies.

    Laggy video: The app is capped at 720p. If it stutters, check your Wi-Fi signal stability.

    Search not working: Make sure yt-dlp is up to date by running the installer again.
